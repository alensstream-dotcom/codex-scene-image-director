# 女性优先筛选说明

本次使用的标准是女性形象为主、男性最多 10 个，保留复古精致插画，只排除有证据的简化卡通脸、Q 版和低精度变体。**画风年代不作为脸部质量指标。** 最新那张 Reverse:1999 风格示例属于应保留的精致插画。

女性和男性的判断依据是源标签，不等于逐个核实官方人设。无外貌标签、性别混杂或资料不足的记录不进入当前抽选库。原始快照和原完整资料包仍保留，排除操作可恢复。

## 脸部筛选的实际范围

已排除 Kemomimi-chan (Naga U)、Lucia (Scott Malin) 等用户明确指出的样例；另排除明确 Q 版变体、`chibi` / `super deformed` / `low poly` 等标签记录，以及南方公园、辛普森一家、海绵宝宝等明显夸张简化卡通系列。具体作者标识和作品名单均保存在 `female-focused.json`，可以逐项调整。

美树沙耶香的 `miki_sayaka` 和 `miki_sayaka_(magical_girl)` 都已确认保留。某一张参考图的脸太简化，不意味着删除整个人物；需要在选图、变体或生图风格层面处理。正常人脸的兽耳、精灵等形象仍可保留；明确兽吻、鸟喙等动物脸证据的兽人记录排除。

**当前没有逐张读取两万多个角色的图片进行脸部评分。** 源数据中的发色、瞳色、发长等标签不足以判断脸部精细程度。所有保留记录的 `profile.face_quality` 均为 `unreviewed`；这保留了真实核实状态，避免按老作品或作者名猜测所有脸的质量。不能声称粗糙脸已经全面清除。

如果以后复核出其他具体粗糙脸，可以把该变体 ID 加入 `excluded_ids` 后重建；不要只因为一张旧图而把正常角色本体或整个作品加入排除列表。LoRA 的画风也应独立记录：复古、绘画质感可以保留，是否精细另行观察。
