# ComfyUI 验收清单

本项目不修改现有工作流，只检查分工是否正确。

## 工作流 A：单人物

- 用于 `1girl, solo`。
- 验证门口、沙发、坐姿、半身和室内日常。
- 主体应占画面主要区域，沙发场景应同时看见沙发与腿。

## 工作流 B：双人物

- 用于 `2girls` 或 `1girl and 1boy`。
- 使用区域提示、人物分区或其他明确的双人控制。
- 验证不同发型、服装、左右位置和动作归属。

## 白边排查

1. 先查看 ComfyUI 原始输出。
2. 原图有白边：检查 latent 宽高、padding、canvas、composite、outpaint 和任何贴图节点。
3. 原图正常、仅酒馆有白边：检查智绘姬容器尺寸、`object-fit` 与主题 CSS。
4. 不用 `no white border` 之类标签掩盖工作流尺寸错误。

只有智绘姬未来提供稳定、公开且经源码核验的工作流选择接口时，救援器才应自动选 A/B；当前版本只根据人数标签提示用户，不猜控制方式。
