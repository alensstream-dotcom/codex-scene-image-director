# 迁移

1. 刷新或重新安装插件，确认版本为1.7.0。
2. 导入 `JANIMA_v8_4_Galgame_Director.json`（内容版本 v8.4），关闭旧 v7.8.2/v7.9/v8.1/v8.2/v8.3 主世界书；FM_DNA 变量数据继续沿用。
3. 关闭更早的自主导演、Fast/Accurate、PRISM 与长期图片记忆功能。
4. 智绘姬保留方括号识别和 ComfyUI 传输，关闭 LLM 扩写与二次改写。
5. 刷新现有聊天后，旧“生图检查”第二列会被自动删除，正文恢复单列。
6. 新生成回复中的 Prompt 必须紧跟剧情；插件会合并同一持续动作，并在检测到前密后疏或漏掉后半段转折时整轮重排，因此真实按钮和图片会回到对应剧情下。
7. 如需插件自动判断漏图/错图，配置 API 并开启后台 AI 审计；不配置时仍有世界书和静默本地纠错。
