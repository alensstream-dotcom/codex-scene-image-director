# 从 0.7.0 迁移

旧版本已由 `pre-rescue-rebuild-0.7.0` tag 和 `master` 分支完整保留，迁移期间不要删除旧世界书或旧插件备份。

1. 关闭旧插件的自主 Prompt 生成、选段导演、Fast/Accurate、PRISM 与长期图片记忆。
2. 关闭所有旧生图世界书，避免多套数量和格式规则冲突。
3. 只启用 `JANIMA_worldbook_rescue_v1`，为实际角色更新 CHARACTER-DNA。
4. 导入三条 JANIMA 正则，UpdateVariable 规则默认关闭。
5. 智绘姬关闭 LLM 扩写、智能分析、二次重写、自动改变角色与自动风格。
6. 保留智绘姬方括号识别、真实生成按钮和 ComfyUI 传输。
7. 新插件只开启本地检查和救援；AI 修复按需启用。
8. 连续测试 20 个场景，确认旧配置无回退需求后再决定是否清理本地旧配置；Git 历史仍保留。

回退代码：切回 `pre-rescue-rebuild-0.7.0`。回退配置时也必须同时恢复与其匹配的旧世界书和智绘姬设置，避免新旧规则混用。
