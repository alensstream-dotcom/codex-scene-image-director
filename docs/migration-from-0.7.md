# 迁移

1. 刷新或重新安装插件，确认版本为1.10.0。
2. 导入 `JANIMA_v8_7_Galgame_PostReply_Director.json`（内容版本 v8.7），关闭旧 v7.8.2/v7.9/v8.1/v8.2/v8.3/v8.4/v8.5/v8.6 主世界书；FM_DNA 变量数据继续沿用。
3. 关闭更早的自主导演、Fast/Accurate、PRISM 与长期图片记忆功能。
4. 智绘姬保留方括号识别和 ComfyUI 传输，关闭 LLM 扩写与二次改写。
5. 刷新现有聊天后，旧“生图检查”第二列会被自动删除，正文恢复单列。
6. 新生成回复先保持纯剧情；完成后插件调用当前模型一次，同时生成整轮 1–6 张 Prompt，并写回对应剧情段落。旧 v8.6 证据包仍可读取，但同步 Prompt 默认关闭。
7. 不需要另填 API；批量分镜复用当前聊天模型连接。外部 API 只用于可选的深度审计。
