# 迁移

1. 刷新或重新安装插件，确认版本为 1.11.5 或更高。
2. 导入 `JANIMA_v8_8_Galgame_SameReply_Ledger_Director.json`（内容版本 v8.8），关闭旧 v7.8.2/v7.9/v8.1–v8.7 主世界书；FM_DNA 变量数据继续沿用。
3. 关闭更早的自主导演、Fast/Accurate、PRISM 与长期图片记忆功能。
4. 智绘姬保留方括号识别和 ComfyUI 传输，关闭 LLM 扩写与二次改写。
5. 刷新现有聊天后，旧“生图检查”第二列会被自动删除，正文恢复单列。
6. 新回复在同一次主模型生成中包含自然剧情和末尾隐藏账本；插件本地生成 1–6 张 Prompt 并写回对应剧情段落。旧 v8.6 证据包仍可读取。
7. 不需要另填 API；默认不发第二次 LLM 请求。外部 API 只用于手动开启的可选深度审计。
