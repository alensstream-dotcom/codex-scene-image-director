# 智绘姬设置与原位按钮

已核验 st-chatu8 2.7.7：真实生成按钮为 `.st-chatu8-image-button`，加载态为 `data-loading="true"`。

推荐设置：

- 模式：ComfyUI。
- 开始标记：`[`；结束标记：`]`。
- 关闭 LLM 扩写、智能分析正文、二次重写 Prompt、自动改变角色与按剧情切换风格。
- 不要另加 Pony 固定串。插件会让世界书 Prompt 以 JANIMA 原生质量块开头，并清空智绘姬追加的重复质量块；不要把 `second girl` 或特定服装永久加入全局负面。
- `safe / sensitive / nsfw / explicit` 由每张剧情内容选择一个；不要在智绘姬固定正向词里永久追加 `safe`。
- `@画师` 只作为可选风格锁：最多一个、必须带 `@`、同一聊天保持不变。默认不使用画师串，避免风格覆盖人物身份和剧情题材。

按钮位置规则：

1. JANIMA v8.8 在同一次主回复末尾输出一个不可见的 `JANIMA_STORYBOARD_V2` 账本，不直接显示 Prompt。
2. 救援器本地把账本原句绑定到对应剧情段落，在该位置生成 `[prompt]`；这一步不请求第二个 LLM。
3. 智绘姬在该字符位置创建真实按钮；救援器只添加原位布局标记，不复制、不新建替代按钮。
4. 救援器会忽略并隐藏 `[Unnamed Persona]`、变量 JSON 数组等不符合图像标签格式的误按钮。
5. 点击后图片仍在同一剧情位置生成。

如果按钮仍堆在底部，先确认只启用 v8.8 主生图世界书、插件为 v1.11.5 或更高，并刷新页面清除旧模块缓存。
