# 架构

```text
主聊天模型
  → JANIMA v8.8 手机 Galgame 世界书（保留 FM_DNA/变量体系）
  → 同一次主回复：完整自然剧情 + 末尾隐藏 JANIMA_STORYBOARD_V2 账本
  → 本地确定性分镜（原句锚定 + 动作阶段 + 女性门禁 + 跨轮身份 DNA/当前服装）
  → Prompt 写回各自剧情段落（不渲染插件 UI）
  → 智绘姬原生按钮
  → JANIMA Galgame Turbo 8 步实时工作流
```

## 世界书

v8.8 让主模型在一次生成中完成自然剧情与一个隐藏的全文分镜账本。账本保存逐字原句、动作施受、结果、状态变化、人物 DNA 与成人阶段；不在聊天中显示 Prompt 或面板。

## 静默插件

插件读取最近 16 条 assistant 消息。最新回复即使完全没有 Prompt 或证据包也会进入检查；即使手机尚未渲染该消息 DOM，也能先在聊天数据中完成分镜。手机滚动时，`IntersectionObserver` 会在旧消息重新进入视口后触发单条重扫。

插件不再发 quiet 请求。它仅在本地对账本执行：正文范围内的原句定位、时间顺序、动作语义、女性在场、人数、成人阶段、不可变外貌与当前服装校验。通过后才把 Prompt 写回对应段落；纯男性/空场景直接为 0。中英标点差异可容错，改写、未来剧情和账本自身不能当正文证据。

st-chatu8 在创建按钮时捕获 Prompt 到点击闭包，因此插件写回新 Prompt 后会移除空的旧按钮，再让 st-chatu8 重建真实按钮。v8.6 的 `JANIMA_SHOT` 证据修复仍作为兼容路径保留。

JANIMA 是 Anima 架构而不是 SD1.5/SDXL UNet，不能直接套用经典 IP-Adapter 工作流。角色连续性由完整逐图 DNA 保持；生成端恢复用户原有 Turbo LoRA，以 8 步实时出图。Prompt 把决定性动作与关键道具放在长人物 DNA 之前，但每张仍重复完整身份锁。

## 按钮原位

st-chatu8 2.7.7 会按 Prompt 在原始回复中的字符位置创建 `.st-chatu8-image-button`。v1.11.5 把 Prompt 插回账本 quote 所在剧情段落；插件在写回结束、生成结束和消息重新进入手机视口时唤醒其原生 DOM 重扫。`[Unnamed Persona]`、JSON Patch 数组、未通过门禁或捕获旧载荷的空按钮会被移除；已有生成媒体的历史节点只隐藏，不破坏图片。

## 可选后台 AI 审计

此功能默认关闭。手动启用后，AI 只能返回删除、替换或在指定段落后插入 Prompt 的 JSON 补丁，不能重写剧情。默认手机路径不需要也不等待该审计。
