# v2.2.2 定点重构审查

审查 64 个运行源文件及两份工作流 JSON。按功能审查过滤器，没有将所有名称含 filter / sanitize 的函数一律短路。实际后端是独立 ComfyUI REST；没有 WebUI / NovelAI 请求构造器。

| 范围 | 处理结果 |
| --- | --- |
| scene-buttons / scene-placement | 根据源标记前正文匹配 DOM，只移动控件，不改存储剧情。已有末尾图片重定位，重复段落按出现次序对应，歧义不猜测。 |
| comfy-transport | 去除全局尺寸文字替换及原文 trim，保留有效最终提示词原文。只解析构图头部独立尺寸项。用户附加正 / 负提示词按原配置拼接，引用文件控制仍显式追加。 |
| workflow-config | 普通默认负面为空，删除旧预设硬编码的整份质量 / 解剖排除列表。更新模板不覆盖用户已保存的负面词。 |
| sanitizeAppearanceText / sanitizeNativePrompt / compactTags | 保留外貌、衣装、镜头约束、角色标记展开及动作精简。短路会重新引入发色漂移和提示词臃肿，也违背保护要求。 |
| 场景提取模板及世界书 | 保留 JSON / ADCAP 约定、非露骨与未成年保护。未删除全部 SFW 条款。用户世界书文件不重写。 |
| 控制标记、路径 / 工作流校验、HTML 处理 | 保留结构和执行安全校验、显示层规划 / 思考隐藏规则。酒馆自身 DOMPurify 不修改。 |
| 后端审核字段 | 插件没有硬编码这些开关；自定义工作流中的安全字段保留原值，未新增 false 开关。 |

本版保证的是有效最终提示词在 ComfyUI 传输边界上的原文保留，并非从剧情提取到出图的 100% 无过滤透传。没有移除未成年性化保护或关闭后端安全机制。

15 个核心源文件与 v2.2.1 字节一致，清单及匹配位置见 refactor-audit.json。场景检测、AutoCG 时机、人物匹配、世界书、镜头逻辑、配置读写和宿主通信流程未改动。
