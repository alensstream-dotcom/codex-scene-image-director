# 剧情绘图工作台 v2.3.0

TauriTavern 的独立剧情绘图插件。选段生图、自动插图、人物外貌、衣装、画风、ComfyUI 工作流和图片缓存都由一个插件管理，运行不需要智绘姬，也不需要电脑上的选段助手服务。

## 本版功能

- 图片按钮与已保存图片按正文位置挂到对应段落下方；选段生图位于选中文字之后。兼容加粗、引号、被显示规则移除的标记及重复段落，旧版落在末尾的图片也会自动纠正。对应正文完全隐藏或无法唯一定位时明确显示「原段落已隐藏」，不会把另一段文字当成原段落。
- 绘图传输保留最终提示词的原文、权重、引号、Unicode、重复标签与尺寸文字。只从 Scene Composition 的独立尺寸项读取画布参数。内置普通 / 旧预设的默认负面提示词均为空；已有用户负面配置保持原样。
- 既有外貌及标签处理仍保留必要约束：外貌 / 衣装约束、动作精简、非露骨与未成年保护、结构及 HTML 安全校验保持。不会关闭后端安全机制。具体扫描结果见 [代码审查记录](verification/refactor-audit.md)。

- 自动、选段和动作重绘的固定模型提示规则全部来自可编辑世界书，不再维护另一份隐藏的选段提示词。完整默认书有 28 条，标注适用阶段与类别；「仅保留必要规则副本」保留 17 条格式、保护和动态事实条目，「追加外部世界书条目」将自己的分享书合并到草稿，保存后生效。提供阶段预览、完整 JSON 编辑、导入导出和删除；原书及未知字段保留。详见 [世界书条目与替换指南](worldbook-authoring.md)。

- 图片标记直接显示为本插件的生图按钮。生成结果保存到自己的本地图片库，重开聊天仍可显示；点图片可查看版本、修改 tags、重绘和保存人物参考。
- 「API 配置」支持地址、密钥、模型、获取模型列表、测试连接，以及多套配置的新增、保存、切换、重命名、导入、导出与删除。默认导出不含密钥或自定义请求头。选段接口独立于主对话接口。
- 「ComfyUI」可设置服务器地址、模型、CLIP、VAE、步数、CFG、尺寸、采样器、调度器和附加提示词。「工作流」支持 API JSON 的新建、导入、编辑、保存、切换、重命名和导出。内置工作流的主模型、CLIP、VAE 与采样参数会使用设置页的值；自定义工作流用 `%prompt%`、`%negative_prompt%`、`%seed%`、`%steps%`、`%cfg_scale%`、`%width%`、`%height%`、`%MODEL_NAME%`、`%clip%`、`%vae%` 等占位符，固定节点值由工作流决定。每张图的 tags 里的尺寸优先。
- 「图片缓存」支持缩略图、时间、人物和日期搜索、当前聊天筛选、分页、多选、全选本页、ZIP 批量下载、删除、大小统计和重算缩略图。删除会原子更新相关聊天记录；被人物档案或重绘快照引用的参考图片保留。
- 可复制导入本地智绘姬 IndexedDB 图片缓存，保留时间和生成参数，按图片内容合并重复副本，原库不改动。视频与缺失原图会跳过。已有图片不会自动重画。
- 保留胸型、身高、瞳色、发色、发长、发型和年龄层的外貌记录，以及动作提示词精简、衣装时序和人物条件交集筛选。原型触发词和图片参考由用户选择。

## 安装

安装仓库链接：`https://github.com/alensstream-dotcom/codex-scene-image-director`。

TauriTavern 可下载 [公开导入包](packages/剧情绘图_v2.3.0_公开TauriTavern导入包.zip)，通过「扩展设置 → 数据迁移 → 导入数据归档」导入后完全退出并重开。归档只有 `animadex-story-cast` 一个绘图插件；默认规则模板在首次运行时生成实际世界书文件。已有旧版时保留该插件设置和图片库，只更新文件；不要同时启用两份剧情绘图插件。智绘姬可停用，原文件和缓存可保留以便迁移。

进入「剧情绘图 → API 配置」保存选段接口，进入「ComfyUI」保存绘图地址，再到「工作流」选择预设或导入 ComfyUI 导出的 API 格式 JSON。已有智绘姬配置只会一次复制必要的绘图与选段配置，后续修改属于本插件，主对话配置保持独立。

手机填写绘图电脑的局域网地址，例如 `http://192.168.1.100:8188`。手机上的 `127.0.0.1` 指向手机自身。两端的缓存各自存储，可以通过插件的备份功能迁移。

安装本插件无需另下载生图世界书。首次运行创建可编辑的「Animadex_剧情绘图_生图规则」，默认按阶段直接发送启用条目，不用手动挂到全局世界书。升级旧版时建立「原书名 · 自动与选段」副本并启用，原文件与用户修改保留；此前已删除或停用的书不会自动恢复。旧「Animadex_剧情绘图_v2_使用指南」只是说明，可以取消挂载或删除；新版不会重装它。用户原世界书不随公开包发布。内置 Anima 工作流需要相应模型、CLIP、VAE 和 `custom_nodes/` 中的节点；模型权重不在仓库。也可以导入自己的标准 ComfyUI 工作流。

## 修改自己的生图世界书

进入「扩展设置 → 剧情绘图 → 世界书」。从正在使用的完整书点击「仅保留必要规则副本」，再点击「追加外部世界书条目」上传自己的 SillyTavern JSON。选择追加内容适用于「自动与选段」「仅自动」或「仅选段」，确认草稿并保存。原完整书保留，新增副本立即成为正在使用的书。每次使用一本生图规则书，第三方绘图指导合并在必要规则之后；不要让第三方输出格式覆盖本插件的 ADCAP / 选段 JSON 格式。

每条规则可以修改内容、类别、阶段、启用状态，或删除。「查看 / 编辑完整 JSON 文件」修改高级字段，「查看当前直接注入内容」按自动或选段预览已保存规则。动态人物与衣装在请求时填入，不写入文件。选段和动作重绘每次请求前也重新读取酒馆文件，编辑后下一次就采用；停用后不会悄悄使用默认选段提示词。

「直接注入」按阶段发送启用条目，忽略关键词、概率及预算。「原生触发」的关键词、概率、预算、位置等扫描只用于自动回复；选段使用独立 API，按阶段发送启用条目，不执行酒馆扫描条件。第三方条目的未知字段仍保留。普通导入建立独立副本且不自动启用；追加导入仅修改草稿，保存后生效。

「导出世界书」下载完整普通世界书 JSON，也支持有效草稿。删除世界书会删除对应酒馆文件；恢复默认新建副本，保留已有修改。手机同样支持编辑、导入、导出、删除。默认 [完整规则文件](worldbook-rules.json) 和 [必要规则文件](worldbook-minimal.json) 都可直接下载，条目逐项说明见 [替换指南](worldbook-authoring.md)。固定模型提示规则在书里；场景监听、人物外貌绑定、标签校验和后端工作流等执行逻辑仍由插件负责，见说明条目。

## 验证与来源

本版本地与公开仓库各 317 项 Node 回归通过。新版世界书桌面 / 手机触摸模拟 38 项、原有世界书界面 20 项、API 配置 20 项、段落图片定位 32 项通过。真实 TauriTavern 12 项验证通过：原文件保留、自动与选段规则分流、原生编辑同步、必要规则加外部指导的导出、主对话 API 不变；另完成一次真实选段模型请求，编辑后的 summary 规则出现在实际请求中且只发送一次，返回内容遵循修改。本次没有新增角色卡对话或重新生成图片，实体手机未连接测试。

角色数据是 21,541 条公开快照，默认检索池 8,000 条。数据、词表及原版迁移解析测试样本的来源与许可见 [SOURCE-NOTICES.md](SOURCE-NOTICES.md)。`fixtures/chatu8-parser.original.js` 是原版解析样本，仅供迁移测试，不会装进插件或在运行时加载。`compat/shujuku` 保留旧版 SP 数据库兼容文件，属于可选历史适配，不是生图依赖。

公开包不含已配置接口密钥、用户设置、聊天、私人角色卡、生成图片或用户原版世界书。插件不能消除外部 API 超时和模型本身的画面随机性。
