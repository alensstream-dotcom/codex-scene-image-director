# JANIMA Galgame 自动CG v5

面向手机 SillyTavern + 电脑局域网 ComfyUI 的自动剧情 CG 扩展。V5 不再让一个模型同时猜人物、服装、场景和最佳镜头，而是把任务拆成两个隔离阶段。

## V5 工作流程

```text
完整正文
→ 状态提取：人物身份 / 当前服装 / 地点 / 在场人物 / 成人阶段
→ 程序构建逐段状态时间线并继承未变化状态
→ 镜头导演只基于冻结状态提出 8–12 个候选镜头
→ MMR 式质量与差异性选择器保留 3–5 张
→ JANIMA 原生工作流生成图片
→ 按渲染文字字符位置插回准确剧情段落
```

## 为什么这样改

以前版本的主要问题来自职责混在一起：

- 镜头导演临时重新猜服装，导致正文写汉服却画成学院装。
- HTML 渲染后的段落数量与原始正文不同，导致图片堆在中间或末尾。
- 为了防扎堆硬选前、中、后，反而会选择低价值剧情。
- 成人阶段虽然被识别，却可能被普通 Prompt 或冲突负面词抵消。

V5 的关键原则是：**状态先冻结，镜头导演不能修改状态。**

## 服装与人物状态

状态提取器会逐段维护：

- 人物稳定外貌：发色、瞳色、脸型、体型等。
- 当前服装。
- 当前地点。
- 当前在场人物。
- 当前成人阶段。

服装更新必须同时满足：

1. 同一段正文存在服装、换装、脱衣或裸体证据。
2. 模型返回该段中的准确证据文字。
3. 插件验证证据确实存在于该段。

验证失败的服装更新会被丢弃；正文没有换装证据时沿用上一状态。

## 镜头选择

V5 不再强制前、中、后各选一张。每个候选镜头根据以下因素评分：

- 剧情重要性。
- 动作是否清晰可画。
- 人物互动和关系变化。
- 情绪、战斗、重要道具、新地点或新服装。
- 成年 NSFW 关键阶段。

相邻段落、相同动作和相同剧情块会受到重复惩罚。最终动态保留 3–5 张。明确成年人的成人阶段仍会保留必要名额，但不会无限占满全部图片。

## 精确图片位置

每个镜头保存：

- 原文准确段落。
- 原始字符起止位置。
- 前后文上下文。

酒馆渲染完成后，插件用 `TreeWalker` 建立屏幕文字到 DOM 文本节点的字符映射，再把图片放到准确取材文字之后。

找不到准确锚点时，V5 不会猜位置。它会把该图片保留在消息末尾并明确显示“定位失败”，方便诊断。

## 成人剧情

成人等级分为：

- `0`：普通场景。
- `1`：接吻、拥抱、暧昧接触。
- `2`：脱衣、裸体或明确触摸。
- `3`：明确成年性行为。

最终 Prompt 会按等级加入相应动作，并删除 `sfw`、`fully clothed`、`no nudity`、`no sex` 等冲突内容。检测到明确未成年证据时不会生成成人图片。

## 模型调用与速度

V5 每条正文会额外调用当前文本模型两次：

1. 状态提取。
2. 镜头导演。

因此比 V4 更慢，也会增加文本模型消耗。换来的好处是人物、服装、地点和选镜头职责完全分离。

## 安装与更新

在 SillyTavern 的“扩展 → 安装扩展”中填写：

```text
https://github.com/alensstream-dotcom/codex-scene-image-director.git
```

已安装时点击更新并彻底刷新页面。设置标题应显示：

```text
JANIMA Galgame 自动CG v5.0.0
```

请用一条全新的回复测试。旧回复保存的 V4 分镜不会自动重新分析。

控制台可查看最新状态和镜头：

```js
JANIMA_AUTO_CG.inspectLatest()
```

## 手机直连 ComfyUI

`ComfyUI 地址` 填写电脑局域网地址，例如：

```text
http://192.168.1.12:8188
```

电脑启动 ComfyUI 时需允许局域网与跨域：

```text
python main.py --listen 0.0.0.0 --port 8188 --enable-cors-header "*"
```

插件使用原生接口：

```text
POST /prompt
GET /history/{prompt_id}
GET /view
```
