# 剧情绘图工作台 v2.2.0

TauriTavern 的独立剧情绘图插件。选段生图、自动插图、人物外貌、衣装、画风、ComfyUI 工作流和图片缓存都由一个插件管理，运行不需要智绘姬，也不需要电脑上的选段助手服务。

## 本版功能

- 图片标记直接显示为本插件的生图按钮。生成结果保存到自己的本地图片库，重开聊天仍可显示；点图片可查看版本、修改 tags、重绘和保存人物参考。
- 「API 配置」支持地址、密钥、模型、获取模型列表、测试连接，以及多套配置的新增、保存、切换、重命名、导入、导出与删除。默认导出不含密钥或自定义请求头。选段接口独立于主对话接口。
- 「ComfyUI」可设置服务器地址、模型、CLIP、VAE、步数、CFG、尺寸、采样器、调度器和附加提示词。「工作流」支持 API JSON 的新建、导入、编辑、保存、切换、重命名和导出。内置工作流的主模型、CLIP、VAE 与采样参数会使用设置页的值；自定义工作流用 `%prompt%`、`%negative_prompt%`、`%seed%`、`%steps%`、`%cfg_scale%`、`%width%`、`%height%`、`%MODEL_NAME%`、`%clip%`、`%vae%` 等占位符，固定节点值由工作流决定。每张图的 tags 里的尺寸优先。
- 「图片缓存」支持缩略图、时间、人物和日期搜索、当前聊天筛选、分页、多选、全选本页、ZIP 批量下载、删除、大小统计和重算缩略图。删除会原子更新相关聊天记录；被人物档案或重绘快照引用的参考图片保留。
- 可复制导入本地智绘姬 IndexedDB 图片缓存，保留时间和生成参数，按图片内容合并重复副本，原库不改动。视频与缺失原图会跳过。已有图片不会自动重画。
- 保留胸型、身高、瞳色、发色、发长、发型和年龄层的外貌记录，以及动作提示词精简、衣装时序和人物条件交集筛选。原型触发词和图片参考由用户选择。

## 安装

安装仓库链接：`https://github.com/alensstream-dotcom/codex-scene-image-director`。

TauriTavern 可下载 [公开导入包](packages/剧情绘图_v2.2.0_公开TauriTavern导入包.zip)，通过「扩展设置 → 数据迁移 → 导入数据归档」导入后完全退出并重开。归档只有 `animadex-story-cast` 一个绘图插件和公开使用指南。已有旧版时保留该插件设置和图片库，只更新文件；不要同时启用两份剧情绘图插件。智绘姬可停用，原文件和缓存可保留以便迁移。

进入「剧情绘图 → API 配置」保存选段接口，进入「ComfyUI」保存绘图地址，再到「工作流」选择预设或导入 ComfyUI 导出的 API 格式 JSON。已有智绘姬配置只会一次复制必要的绘图与选段配置，后续修改属于本插件，主对话配置保持独立。

手机填写绘图电脑的局域网地址，例如 `http://192.168.1.100:8188`。手机上的 `127.0.0.1` 指向手机自身。两端的缓存各自存储，可以通过插件的备份功能迁移。

使用指南世界书会由插件自动安装，自动绘图协议也会直接注入。安装本插件无需另下载生图世界书。用户原世界书不随公开包发布。内置 Anima 工作流需要相应模型、CLIP、VAE 和 `custom_nodes/` 中的节点；模型权重不在仓库。也可以导入自己的标准 ComfyUI 工作流。

## 验证与来源

280 项 Node 回归通过。API 设置 20 项、既有触摸流程 15 项和独立缓存界面 21 项通过。停用智绘姬后完成两次真实按钮出图、重绘入口和重启恢复，再完成一次真实角色卡新回复自动生图。图像逐张核对外貌与衣装；尺寸记录与图片实际尺寸一致。实体手机未连接测试，手机界面使用触摸浏览器模拟。

角色数据是 21,541 条公开快照，默认检索池 8,000 条。数据、词表及原版迁移解析测试样本的来源与许可见 [SOURCE-NOTICES.md](SOURCE-NOTICES.md)。`fixtures/chatu8-parser.original.js` 是原版解析样本，仅供迁移测试，不会装进插件或在运行时加载。`compat/shujuku` 保留旧版 SP 数据库兼容文件，属于可选历史适配，不是生图依赖。

公开包不含已配置接口密钥、用户设置、聊天、私人角色卡、生成图片或用户原版世界书。插件不能消除外部 API 超时和模型本身的画面随机性。
