# 剧情绘图工作台 v2.1.9

为 TauriTavern 制作的 SillyTavern 剧情绘图插件。选段生成与自动插图共用人物档案、衣装状态和独立图片库；使用本地 Animadex 数据查询角色原型，并通过智绘姬传输到 ComfyUI。

## 本版修复

- 外貌按胸型、身高、瞳色、发色、发长、发型、年龄层保存。小女孩、少女、少妇/成熟女性为外貌类别，具体年龄另存，不推断婚姻状态。未说明的字段不编造；未成年人使用中性描述。
- 明确剧情事实修正旧错误档案。按聊天时间保留最早明确设定；明确染发或剪发才更新。用户编辑的外貌优先。
- 自动选中的角色原型默认不把动漫角色名、作品名、兽耳和发饰塞进图片提示词。原型识别词可以由用户显式开启。
- 候选使用全部已知条件的交集，排除互相矛盾的发色、发长、瞳色和胸型；无条件全符合的记录时保留剧情外貌，不拿相似原型替换。
- 简单动作只保留必要构图、场景、外貌、服装、动作和道具，去掉重复主体、光线及无依据五官段落。
- 双人全身镜头将七项外貌和衣装写在各自左右位置的同一个归属句中，减少提示词正确但画面衣装互换的问题。用户手改 tags 有明确标记，更新不会自动覆盖。
- 主对话为空或返回 API 错误时给出相应任务状态，不把接口问题当作普通无插图标记。

## 安装与更新

本插件需要本仓库附带的 **st-chatu8 传输适配版**；原版智绘姬不具备本插件使用的版本 2 传输接口。不要同时加载旧版 `codex-scene-image-director` 和新版 `animadex-story-cast`，否则可能注册两套绘图钩子。

1. TauriTavern 推荐下载仓库 `packages/` 中的公开导入包，通过「扩展设置 → 数据迁移 → 导入数据归档」导入，然后完全退出并重开。
2. 手动安装时：仓库根目录运行文件放入 `data/extensions/third-party/animadex-story-cast/`；`companions/st-chatu8/` 放入 `data/extensions/third-party/st-chatu8/`。已使用旧版的用户应先备份并移除旧版运行目录，只启用一份剧情绘图插件。更新会保留各自设置，不应删除整个用户数据目录。
3. `compat/shujuku/` 是此前为 SP 数据库 9.2.5 适配的两个文件，仅在相同版本上按需更新，不是绘图依赖。
4. 在绘图设置中选择可用的 ComfyUI API 工作流和模型。附带工作流需要对应 Anima 模型、CLIP、VAE 与相关节点；`custom_nodes/` 内的两个目录放入 ComfyUI 的同名目录后重启 ComfyUI。模型权重不在仓库内。

普通 SillyTavern 尚未做服务器安装验收。手机入口做过触摸浏览器模拟，实体手机未连接验收。

## 数据与来源

运行数据包含 21,541 条角色记录，默认检索池 8,000 条。它是公开快照，不是 Animadex 站点的实时数据库。新增身高、年龄分类只由已有来源标签推导；没有证据的记录不会声称具备对应条件。

原始快照、词表衍生资料及构建代码见 `catalog-source/`，来源说明见 [SOURCE-NOTICES.md](SOURCE-NOTICES.md)。智绘姬相关代码和词表保留 AFPL 许可证，Animadex 数据来源的声明随附，不把整个包标成 MIT。

仓库和公开导入包不含用户 API 密钥、设置、聊天、私人角色卡或用户原版世界书。内置世界书是插件使用指南。历史图片不会被自动重画；重绘时重新应用外貌规则。

## 验证

运行公开回归：`node scripts/run-tests.mjs`。本机完整回归另外含读取用户预设的兼容检查，该私人预设不公开发布。真实出图结论与已知限制见 [verification/acceptance.md](verification/acceptance.md)。纯 tags 能约束发色和着装，但不能保证扩散模型每次绘制完全相同的脸；严格面部一致性仍需要参考图或专用角色模型。

旧版运行文件已被这一版替换，旧提交仍可从 Git 历史查看。
