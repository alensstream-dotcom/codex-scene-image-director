# 剧情绘图工作台 v2.2.2

TauriTavern 的独立剧情绘图插件。选段生图、自动插图、人物外貌、衣装、画风、ComfyUI 工作流和图片缓存都由一个插件管理，运行不需要智绘姬，也不需要电脑上的选段助手服务。

## 本版功能

- 图片按钮与已保存图片按正文位置挂到对应段落下方；选段生图位于选中文字之后。兼容加粗、引号、被显示规则移除的标记及重复段落，旧版落在末尾的图片也会自动纠正。对应正文完全隐藏或无法唯一定位时明确显示「原段落已隐藏」，不会把另一段文字当成原段落。
- 绘图传输保留最终提示词的原文、权重、引号、Unicode、重复标签与尺寸文字。只从 Scene Composition 的独立尺寸项读取画布参数。内置普通 / 旧预设的默认负面提示词均为空；已有用户负面配置保持原样。
- 本次不是将全部过滤函数短路：外貌 / 衣装约束、动作精简、非露骨与未成年保护、结构及 HTML 安全校验保持。不会关闭后端安全机制。具体扫描结果见 [代码审查记录](verification/refactor-audit.md)。

- 「世界书」提供实际生图规则的条目编辑、新建、保存、另存为、启用 / 停用、完整 JSON 导入导出、删除条目及删除世界书。可以查看直接注入预览，并打开酒馆原生世界书编辑器。保存后下一轮采用，重启 / 更新不覆盖用户修改或恢复已删除的规则。导入保留所有字段，重名创建副本，导入书默认不启用。

- 图片标记直接显示为本插件的生图按钮。生成结果保存到自己的本地图片库，重开聊天仍可显示；点图片可查看版本、修改 tags、重绘和保存人物参考。
- 「API 配置」支持地址、密钥、模型、获取模型列表、测试连接，以及多套配置的新增、保存、切换、重命名、导入、导出与删除。默认导出不含密钥或自定义请求头。选段接口独立于主对话接口。
- 「ComfyUI」可设置服务器地址、模型、CLIP、VAE、步数、CFG、尺寸、采样器、调度器和附加提示词。「工作流」支持 API JSON 的新建、导入、编辑、保存、切换、重命名和导出。内置工作流的主模型、CLIP、VAE 与采样参数会使用设置页的值；自定义工作流用 `%prompt%`、`%negative_prompt%`、`%seed%`、`%steps%`、`%cfg_scale%`、`%width%`、`%height%`、`%MODEL_NAME%`、`%clip%`、`%vae%` 等占位符，固定节点值由工作流决定。每张图的 tags 里的尺寸优先。
- 「图片缓存」支持缩略图、时间、人物和日期搜索、当前聊天筛选、分页、多选、全选本页、ZIP 批量下载、删除、大小统计和重算缩略图。删除会原子更新相关聊天记录；被人物档案或重绘快照引用的参考图片保留。
- 可复制导入本地智绘姬 IndexedDB 图片缓存，保留时间和生成参数，按图片内容合并重复副本，原库不改动。视频与缺失原图会跳过。已有图片不会自动重画。
- 保留胸型、身高、瞳色、发色、发长、发型和年龄层的外貌记录，以及动作提示词精简、衣装时序和人物条件交集筛选。原型触发词和图片参考由用户选择。

## 安装

安装仓库链接：`https://github.com/alensstream-dotcom/codex-scene-image-director`。

TauriTavern 可下载 [公开导入包](packages/剧情绘图_v2.2.2_公开TauriTavern导入包.zip)，通过「扩展设置 → 数据迁移 → 导入数据归档」导入后完全退出并重开。归档只有 `animadex-story-cast` 一个绘图插件；默认规则模板在首次运行时生成实际世界书文件。已有旧版时保留该插件设置和图片库，只更新文件；不要同时启用两份剧情绘图插件。智绘姬可停用，原文件和缓存可保留以便迁移。

进入「剧情绘图 → API 配置」保存选段接口，进入「ComfyUI」保存绘图地址，再到「工作流」选择预设或导入 ComfyUI 导出的 API 格式 JSON。已有智绘姬配置只会一次复制必要的绘图与选段配置，后续修改属于本插件，主对话配置保持独立。

手机填写绘图电脑的局域网地址，例如 `http://192.168.1.100:8188`。手机上的 `127.0.0.1` 指向手机自身。两端的缓存各自存储，可以通过插件的备份功能迁移。

安装本插件无需另下载生图世界书。首次运行创建可编辑的「Animadex_剧情绘图_生图规则」，默认直接发送所有启用条目，避免被世界书预算挤掉；这本书不用手动挂到全局世界书。旧「Animadex_剧情绘图_v2_使用指南」只是说明，可以取消挂载或删除；新版不会重装它。导入的普通世界书默认按酒馆原生关键词、概率、预算、位置等条件触发，使用前可选择注入方式。用户原世界书不随公开包发布。内置 Anima 工作流需要相应模型、CLIP、VAE 和 `custom_nodes/` 中的节点；模型权重不在仓库。也可以导入自己的标准 ComfyUI 工作流。

## 修改自己的生图世界书

进入「扩展设置 → 剧情绘图 → 世界书」。选中条目修改正文，点击「保存世界书」，下一轮回复就会使用保存内容。「查看 / 编辑完整 JSON 文件」可以修改高级字段；「查看当前直接注入内容」显示规则与当前聊天的动态人物、衣装事实，动态事实不写进世界书文件。默认规则中的 ADCAP JSON 格式是生图按钮识别约定，改变它可能使自动插图无法识别。

「导出世界书」下载普通 SillyTavern JSON，也能导出尚未保存的有效草稿。「导入世界书」建立独立副本、完整保留字段，确认后点击「使用此世界书」。从「查看酒馆已有世界书」能打开原版编辑器，或复制完整原书到插件管理；原书不改动。「直接注入」发送全部启用条目，忽略关键词和概率；「原生触发」遵循酒馆扫描机制，可能受预算限制。每次只使用一本生图规则书。

删除世界书会删除对应酒馆文件，并停止该书的规则注入。恢复默认时新建副本，保留已有修改。升级不重装已删除的规则；要恢复请主动点击「恢复默认规则副本」。导出 JSON 可在电脑编辑后重新导入，手机同样支持条目编辑和文件导入导出。

## 验证与来源

299 项 Node 回归通过。本次另有 32 项桌面 / 触摸定位检查和 22 项真实酒馆格式化 / 当前聊天位置检查通过；原有 76 项触摸界面回归通过。世界书触摸界面 20 项、API 设置 20 项、既有触摸流程 15 项和独立缓存界面 21 项通过。本机世界书文件读写、原生编辑同步、去重注入、原生扫描、删除重启等 13 项检查通过；另完成一次使用编辑后世界书的真实角色卡自动生图，约束出现在实际请求且只发送一次，生成结果采用编辑后的 summary 规则。停用智绘姬后完成两次真实按钮出图、重绘入口和重启恢复，再完成一次真实角色卡新回复自动生图。图像逐张核对外貌与衣装；尺寸记录与图片实际尺寸一致。实体手机未连接测试，手机界面使用触摸浏览器模拟。

角色数据是 21,541 条公开快照，默认检索池 8,000 条。数据、词表及原版迁移解析测试样本的来源与许可见 [SOURCE-NOTICES.md](SOURCE-NOTICES.md)。`fixtures/chatu8-parser.original.js` 是原版解析样本，仅供迁移测试，不会装进插件或在运行时加载。`compat/shujuku` 保留旧版 SP 数据库兼容文件，属于可选历史适配，不是生图依赖。

公开包不含已配置接口密钥、用户设置、聊天、私人角色卡、生成图片或用户原版世界书。插件不能消除外部 API 超时和模型本身的画面随机性。
